# Frontend

Структура построена по распространённой для небольших SPA схеме `src/{data,services,ui,styles}`: данные и API-адаптер изолированы от представлений и точки входа.

Запуск без сборщика: откройте `index.html` через любой статический сервер, например расширение Live Server в VS Code. Маршруты реализованы hash-навигацией, поэтому серверная настройка для них не нужна.
`src/services/forum-api.js` — единственное место, где моки заменяются вызовами реального API.
